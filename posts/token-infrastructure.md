# 为什么 Token 也成了新基建？

> 电有电表，水有水表，带宽有流量计。现在，智能也有了它的"抄表单位"——Token。当一家公司的财报里开始出现"每月处理 980 万亿个 Token"这种数字时，事情就不只是"AI 好用"这么简单了：**智能正在被当成水电一样的基础设施来生产、计量和定价**。这篇文章用可核实的官方数据，讲清楚 Token 是怎么一步步变成基建的。

![高压输电线路](https://thumb.wikimedia.org/wikipedia/commons/thumb/b/b4/High_voltage_transmission_towers_and_lines.jpg/960px-High_voltage_transmission_towers_and_lines.jpg)
*电网是上个时代最重要的基建：发电、输电、计量、按度收费（图：Wikimedia Commons）*

## 一、Token：智能的"千瓦时"

Token 是大模型处理文本的基本单位——大约 0.75 个英文单词或半个到一个汉字（分词原理见我上一篇文章《AI 大模型是如何计算 Token 的》）。模型读你的问题、生成回答，全过程都按 Token 计数。

![成排的电表](https://thumb.wikimedia.org/wikipedia/commons/thumb/c/ce/India_-_Kolkata_electricity_meters_-_3832.jpg/960px-India_-_Kolkata_electricity_meters_-_3832.jpg)
*电表是把"电"变成"商品"的关键：可计量，才能可交易（图：Wikimedia Commons）*

关键是它的**双重身份**：

- 对**用户**，Token 是消耗品——一次对话、一次代码补全，就是一次"用电"；
- 对**厂商**，Token 是产品——GPU 集群"烧电"产出的商品，按量售卖。

一个东西能成为基建，首先要能被**大规模生产、统一计量、按需售卖**。Token 恰好三条全占：它由数据中心批量"生产"，以百万/千万为单位计量，通过 API 按量计费。这就是"基建化"的物理基础。

## 二、需求侧：Token 消耗量正在指数爆炸

看三家公司官方披露的数字（都来自财报电话会或官方发布会，非自媒体转述）：

| 主体 | 披露渠道 | 数据 |
|------|---------|------|
| Google | 2025 Q2 财报电话会（2025-07） | 月处理 Token 量超 **980 万亿**，较 5 月 I/O 大会公布的 480 万亿**两个月翻倍** |
| Microsoft | FY25 Q3 财报电话会（2025-04） | 单季处理超 **100 万亿** Token，**同比 5 倍**；仅 3 月一个月就 50 万亿 |
| 字节跳动·火山引擎 | 2025 冬季 FORCE 原动力大会（2025-12） | 豆包大模型**日均使用量突破 50 万亿** Token，同比增长超 10 倍，中国第一、全球第三 |

豆包的增长曲线最能看出"基建化"的陡峭程度：

```
2024-05   日均 0.12 万亿（1200 亿）
2024-12   日均 4 万亿        （半年 ×33）
2025-05   日均 16.4 万亿     （半年 ×4）
2025-12   日均 50 万亿+      （半年 ×3，同比 ×10+）
```

两年时间，日均调用量涨了约 **400 倍**。这个斜率只在水、电、通信这些基建品的历史早期出现过。而且 Microsoft CFO 明确表示 AI 产能"供不应求将持续到财年末"——**基建品的第一特征就是：需求增速快于产能建设速度**。

## 三、供给侧：智能的单价崩了，像当年的电力

需求爆炸的同时，单位价格在暴跌。斯坦福 HAI《AI Index 2025 报告》（2025-04 发布）给出了最权威的追踪：

> 达到 GPT-3.5 同等性能的模型，推理成本从 **2022 年 11 月的 $20 / 百万 Token**，降到 **2024 年 10 月的 $0.07 / 百万 Token**——约 18 个月下降 **280 倍**。

配套的两个官方数字：同等性能硬件成本**每年下降约 30%**，硬件能效**每年提升约 40%**。风投 a16z 给这个现象起了个名字——**LLMflation**：固定能力模型的推理价格大约**每年下降 10 倍**。

对比一下电的历史：1900 年前后，电是奢侈品，只有工厂和富人用得起；随着发电规模化和电网铺设，电价持续下降，才有了"插座里长出来的现代生活"。**Token 正在走同一条路：单价降到某个阈值之下后，应用形态会爆发式涌现**——去年还嫌贵的 AI 客服、长文摘要、代码 Agent，今年都成了"随便用"的日常。

## 四、生产端：数据中心正在变成"Token 工厂"

![NVIDIA G71 GPU](https://thumb.wikimedia.org/wikipedia/commons/thumb/2/2b/NVidia_G71_GPU.jpg/960px-NVidia_G71_GPU.jpg)
*GPU 诞生时是渲染游戏的芯片，如今是批量生产 Token 的"发动机"（图：Wikimedia Commons）*

英伟达 CEO 黄仁勋在 GTC 2025 主题演讲中把这件事说得很直白：

> "我称它们为 **AI 工厂**，因为它们只有一个工作：生成 Token——我们再把这些 Token 重构成音乐、文字、视频、研究、化学品和蛋白质。过去我们编写软件、在计算机上运行；未来，计算机会为软件生成 Token。从检索式计算，到生成式计算。"

他还给了两个关键判断：全球数据中心建设支出将在 2028 年前后达到**万亿美元量级**；以及那句行业共识——**"我们现在是电力受限的行业"（We are now a power-limited industry）**。

![数据中心机房](https://thumb.wikimedia.org/wikipedia/commons/thumb/8/80/Data_Center_2_%28UNC%29.jpg/960px-Data_Center_2_%28UNC%29.jpg)
*Token 工厂的车间：每一排机柜都是一条智能生产线（图：Wikimedia Commons）*

电力约束有官方数字支撑。国际能源署（IEA）2025 年 4 月《能源与 AI》报告：

> 2024 年全球数据中心用电约 **415 TWh**，占全球用电的 **1.5%**；到 2030 年将翻倍至约 **945 TWh**——相当于日本全年的用电总量。

![变电站与变压器](https://thumb.wikimedia.org/wikipedia/commons/thumb/f/f9/Substation_switchgear_and_transformer_-_geograph.org.uk_-_3665144.jpg/960px-Substation_switchgear_and_transformer_-_geograph.org.uk_-_3665144.jpg)
*Token 工厂的上游仍然是电网：智能的原料是电（图：Wikimedia Commons）*

生产 Token 的原料从"电"变成了"电 + 芯片 + 数据"，但产业链的逻辑和发电厂一模一样：重资产、长周期、规模效应显著、谁有电力谁有话语权。企业侧的动作也印证了这一点——字节跳动 2026 年计划投入约 1600 亿元加码 AI（《金融时报》2025-12 报道），各大云厂商的资本开支全线飙升。

## 五、为什么说它已经是"基建"：四个特征对照

把 Token 和传统基建逐条对照，会发现它已经满足基建的全部核心特征：

| 基建特征 | 电力 | Token |
|---------|------|-------|
| **规模生产** | 发电厂规模化发电 | 数据中心 GPU 集群规模化推理 |
| **计量计费** | 电表 + 每度电价 | API 计数 + 每百万 Token 单价 |
| **标准接口** | 插座 / 电压标准 | 统一的 Chat Completions API / OpenAI 兼容格式 |
| **规模降价** | 电价随电网普及持续下降 | 固定能力价格每年约降 10 倍（LLMflation） |
| **社会依赖** | 停电 = 生产中断 | 模型限流/宕机 = 应用停摆、企业业务中断 |

最后一条最有说服力：2023 年 ChatGPT 短暂宕机时，成千上万嵌入了它的产品跟着不可用——**当社会运行开始依赖某个东西的持续供应，它就已经是基建了**，无论它叫"电厂"还是"模型"。

国内厂商也在自觉扮演"电网"角色：火山引擎在 2025 年底推出了业内首个"AI 节省计划"（阶梯折扣最高省 47%），6 月起首创按输入长度区间定价、智能模型路由——这些全是公用事业式的定价策略，目的只有一个：**让 Token 像"度电成本"一样可预期、可优化**。

## 六、对开发者和企业的启示

**1. 把 Token 当预算科目管理**
像设计电费预算一样设计 Token 预算：简单任务用便宜的小模型（或缓存命中），复杂任务才路由到大模型。选型时看的不是"哪个模型最强"，而是"每解决一单业务花多少 Token 钱"。

**2. 关注"每瓦特 Token 数"**
黄仁勋说收入上限由电力决定；对企业来说，成本下限由架构效率决定。KV Cache 复用、提示词精简、输出长度控制，都是"省电"动作。

**3. 警惕单一供应商锁定**
基建时代的正确姿势是多回路供电：核心业务至少留一条备用模型通道，API 标准化让切换成本足够低。

**4. 押注"降价红利"**
今天因单价太贵做不了的产品，一年后可能正好落在成本甜区。把"Token 单价下降"当作产品路线图的既定参数，而不是惊喜。

## 结语

基建的定义从来不是"很重要"，而是：**大规模生产、标准化计量、按需售卖、社会运行依赖**。Token 在 2024~2025 这两年间，四条全部达标——需求侧月调用量从几十万亿奔向近千万亿，单价 18 个月降 280 倍，生产端资本开支进入万亿美元赛道，应用端宕机即停摆。

上一次人类给"看不见的资源"装上电表、铺满插座，造就了整个现代工业。这一次，插座里流出来的是智能。
